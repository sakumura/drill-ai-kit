# 志望校同帯 国語過去問 分析 — 出題傾向アンカー（合成サンプル）

> **これは合成データです。** 架空学園中等部と同じ偏差値帯の学校を想定した国語アンカーの記入例。
> 国語は志望校の過去問が入手しにくい場合、同帯（偏差値±5）の学校の過去問で代替してよい。
> exam_transfer 国語ブロックの設問形式・出典テーマ・難易度の出題根拠。

## 国語 d 判定基準

| d | 判定基準 |
|---|---|
| d2 | 漢字の読み書き・語彙の直接問い。本文参照不要 |
| d3 | 傍線部の言い換え・指示語。根拠が傍線の前後3行以内 |
| d4 | 心情の変化・行動の理由。根拠が段落をまたぐ、または2つの心情を切り分ける |
| d5 | 記述（要約・二要素）。本文全体の構造理解が必要 |

## 弱点タグ凡例

- `naiyou-gacchi`: 内容合致（本文と選択肢の照合）
- `shinjou-henka`: 心情の変化（2心情の切り分け）
- `shijigo`: 指示語の指す内容
- `setsuzoku`: 接続語の選択

## セクション構造（同帯校の典型形式）

| 大問 | 形式 | 配点 | 想定 d |
|---|---|---|---|
| 大問一 | 漢字の読み書き 10問 | 20点 | d2 |
| 大問二 | 語句・慣用句 5問 | 10点 | d2-d3 |
| 大問三 | 物語文（心情・行動理由・内容合致） | 40点 | d3-d5 |
| 大問四 | 説明文（指示語・接続語・要旨） | 30点 | d3-d4 |

## 出題傾向メモ（同帯3校の共通項）

1. 物語文は「心情が変化する場面」が必ず出題範囲に含まれる → shinjou-henka を evidence_first で毎週反復
2. 選択肢は「本文に書いていない内容」を混ぜる形式が主流 → naiyou-gacchi の distractor は「無記載型」を優先
3. 説明文は指示語の直前直後で解ける問題が7割 → shijigo は d3 の短文型で量を回す
4. 記述は20〜40字の理由記述が1問。二要素（きっかけ+心情）の型で対策する
