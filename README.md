# juken-ai-kit

> **[!IMPORTANT]**
> 学習者のデータ（成績・弱点プロファイル・答案画像等）を入れて運用する場合、
> 複製時点からこのリポジトリは **必ず private** にしてください。public repo は
> 同梱の合成データを確認するためだけの形です。実データを入れてから private に
> 変更する運用は、git 履歴や fork に残るため禁止です。実データを入れたら、
> 基本的にずっと private のままにする想定です。それでも public にする場合は
> 必ず [`PUBLICATION_SAFETY.md`](./PUBLICATION_SAFETY.md) を読んでください
> （外部AIへのデータ送信範囲、教材の著作権、公開範囲の事故防止をまとめています）。

AIと運用する、受験・資格試験向けのパターン暗記ドリルキット（テンプレート）。

「AIに問題を作らせるツール」ではなく、**記録 → 分析 → 設計 → 生成 → 検証 → 配信**の
ループが毎日回る小さな学習システムです。実際に1つの家庭で毎日運用されているシステムを、
中学受験サンプル付きの汎用試験ドリルキットとして、固有情報を除いてテンプレート化しました。

同梱データは中学受験を例にしていますが、仕組み自体は、頻出知識・典型判断・分類ラベル・
解法パターンを反復して定着させる試験学習に転用できます。

## 何ができるか

- 学習者がブラウザでドリルを解く（スマホ・タブレット対応。6種の問題形式 + スケッチゲート）
- 一問ごとの解答が記録され、弱点プロファイルが自動更新される
- Claude Code が、昨日の間違いに基づいて翌日のレッスンを生成する
- 生成された問題は**4層の検証ゲート**（機械検証 → 図形視覚検証 → 自己解答 → セマンティックレビュー）を通過したものだけが配信される

## 3つの層

| 層 | 中身 | 場所 |
|---|---|---|
| アプリ | React 19 + Vite / Hono on Cloudflare Workers + R2 | `frontend/` `workers/` |
| 生成・検証パイプライン | 問題銀行、検証ゲート、ログ分析、弱点プロファイル構築 | `scripts/` |
| AI運用スキル | briefing / generate-drill-lesson / analyze-test / fetch-school-kakomon / dogfood / deploy / setup | `.claude/skills/` |

アプリ単体なら quiz app にすぎません。差別化の実体は 2層目・3層目です。

## 想定利用者と要求水準

正直に書きます。このキットのハードルは高く、それは意図的です。

- **Cloudflare アカウント**を持てる（または作れる）こと（小規模な家庭利用なら無料枠中心の構成で動きますが、料金体系はサービス側の変更に依存するため断定はしません）
- **Claude Code など高性能な外部AIエージェントを使う意思**があること。セットアップも日々のレッスン生成も、外部AIに任せる前提の設計です。性能の低いローカルLLMだけで実戦運用する前提ではありません
- 外部AIは、原則として月額定額サブスクで使います。従量課金APIを日次運用の主筋にすると、コストが読みにくく破綻しやすいため推奨しません
- ここで要求しているのは技術力ではありません。**「AIに任せる決断」と「学習に毎日付き合う本気度」**です。セットアップ自体はAIエージェントが代行できます（`SETUP.md`）

### なぜ Claude Code を推奨するか

- **claude-in-chrome**: Cloudflare のアカウント作成・ダッシュボード確認など、ブラウザ操作が要る場面もAIに委譲できる
- **Claude Design**: ドリルアプリの見た目を変えたくなったとき、DESIGN.md のトークン運用も含めてAIに任せられる

他のAIエージェントでも Part 2 の手順自体は実行できますが、上記2点の委譲能力は失われます。

## 始め方

1. Claude Code を開く
2. このリポジトリのURL（`https://github.com/sakumura/juken-ai-kit`）を貼って、「これを自分用にセットアップして」と伝える
3. 途中でアカウント作成やブラウザでの承認を求められたら、その都度対応する

あとは複製、ダウンロード、必要な設定、配信環境の準備、動作確認まで、AIエージェントが順番に進めてくれる。コマンドを覚えたり自分で打ったりする必要はない。実運用するなら「複製したリポジトリは必ず private にする」ことだけは自分で確認する（詳しくは `PUBLICATION_SAFETY.md`）。

作業の詳しい中身は `SETUP.md` にまとめてあるが、これはAIエージェントが読む手順書であり、人間が目を通す必要はない。

## 同梱の合成データ

clone 直後から全パイプラインがデモ実行できるよう、**すべて架空の合成データ**を同梱しています:

- 架空の志望校「架空学園中等部」の難易度アンカー・過去問分析・長期計画（`data/target-school/`）
- 合成カリキュラム・弱点プロファイル・数日分のプレイログ（`data/`）
- サンプルレッスン2本（`data/lessons-handwritten/`。テンプレ自身の generate-drill-lesson 手順と検証ゲートで生成）

実際の学習者データ・実在の塾や学校、または資格試験の出題範囲分析に差し替えると「自分専用」になります。
差し替え手順は `SETUP.md` の後半を参照してください。

## 大事な注意

**実運用（実データ投入）を始める前は必ず [`PUBLICATION_SAFETY.md`](./PUBLICATION_SAFETY.md) を読んでください。実データを入れたら、リポジトリは基本的にずっと private のままにする想定で、public に戻すことは推奨しません。** 要点だけ以下に再掲します:

- **塾の教材・過去問などの著作物は、このリポジトリにコミットしないでください。** `data/textbooks/` 配下は gitignore 済みのローカル資産として扱う設計です。**購入・契約済みの教材でも、OCR・外部AIへの送信・再配布が自動的に許可されるわけではありません**（塾・出版社・模試会社の規約を確認してください）
- 学習者の成績・学習記録は個人情報です。リポジトリを public にしないでください（テンプレート複製時は private 必須）
- **「リポジトリの公開範囲」と「アプリのURLが動くこと」は別物です。** アプリはCloudflareの `*.pages.dev` 等のURLで動きますが、これは不特定多数への公開ではなく、URLを知っている人だけが使う専用アプリという位置づけです。覚えやすさのために独自ドメインを付けると発見されやすくなるため、付けないことを推奨します（詳細は `SETUP.md` と `PUBLICATION_SAFETY.md`）
- **このキットは外部AI利用を前提にします。** 実運用前に、使うAIサービス（Claude Code / Codex / Gemini / Cloudflare Workers AI 等）の学習利用拒否・データ保持・人間レビュー設定を確認し、可能な限り学習利用を拒否してください
- **スケッチゲート（指描き判定）は学習者の手書き画像を Cloudflare Workers AI（サードパーティのAIモデル）に送信します。** 縮小画像は R2 の `sketch_log/` にも保存されます。この機能を使わない場合は、レッスンJSONで `sketch_gate` を使わなければ発火しません
- テスト分析時、答案・成績画像を複数の外部LLM（Claude/Codex/Gemini等）に送って照合する仕組みがあります。**実行前に、送信先・学習利用拒否設定・送る資料を確認し、保護者の承認を必須化**しています。承認するかどうかは都度自分で判断してください
- 生成された問題文・図・音声には、第三者が権利を持つ教材・過去問の文章や図を**そのまま複製しない**設計です（`_shared/question-rules.md` の丸写し禁止ルール）。ただし最終的な著作権判断は利用者の責任です
- パスワード・2FAコード・APIトークンはAIエージェントに渡さない。課金・削除・公開範囲変更・OAuth承認は必ず人間が最終操作する
