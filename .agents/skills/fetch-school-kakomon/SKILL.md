# Fetch School Kakomon — 学校公式サイトの無料公開過去問を取得する

多くの中学・高校は、受験生向けに自校の入試過去問を**自校の公式サイト上で無料公開**している。
このスキルはその一次情報だけを対象にし、個人ブログ・まとめサイト・塾の会員限定ポータルなど
**第三者が権利者の許諾なく転載している過去問には一切触れない**設計にする。

`_shared/question-rules.md` の丸写し禁止ルール、`PUBLICATION_SAFETY.md` §4（教材の著作権）と
一貫した運用にすること。

## 入口

```
/fetch-school-kakomon "架空学園中等部"
/fetch-school-kakomon "架空学園中等部" --prefecture 長野県
```

## 原則（絶対に譲らない）

1. **公式ドメインのみ**: ダウンロード対象は、学校自身が運営していると確認できたドメイン
   （学校名・所在地・入試情報が一致する公式サイト）に限る。第三者サイト・まとめサイト・
   塾のポータル・過去問販売サイトは対象外
2. **ログイン・登録・支払いの回避を目的にしない**: 会員登録や購入が必要なページに到達したら停止する。
   ログイン情報の入力・課金は行わない（`PUBLICATION_SAFETY.md` §4）
3. **公式ドメインの確定は人間に確認を取ってから次に進む**: 検索結果からの自動判定は誤認しうる。
   候補URLを提示し、保護者が「これで合っている」と確認してから Step 3 のダウンロードへ進む
4. **無料公開されていない学校は無理に探さない**: 公式サイトに過去問公開ページが見当たらない場合、
   第三者サイトや推測URLへのフォールバックはしない。「この学校は公式サイトでの無料公開が
   確認できなかった」と報告して終了する
5. **取得しても著作権は学校に帰属する**: 無料公開＝自由利用可、ではない。個人の受験対策目的の
   閲覧・分析に留め、再配布・商用利用はしない

## Step 1. 学校名の確認

- 学校の正式名称・所在地（都道府県）・学校種別（中学/高校/中高一貫）を確認する
- 曖昧な場合（同名校が複数ある等）は保護者に確認する

## Step 2. 公式サイトと過去問公開ページの検索

```
WebSearch: "<学校名> 公式サイト"
WebSearch: "<学校名> 過去問 PDF"
WebSearch: "<学校名> 入試問題 公開"
WebSearch: "<学校名> 学校説明会 過去問 配布"
```

見つけたドメインについて、以下を確認してから「公式サイト候補」とする:

- 学校名・所在地・入試情報（募集要項、学校説明会日程等）がそのドメイン上に存在する
- ドメインが学校法人・学校名を冠している、または学校が公表している正式URLと一致する
- 過去問販売サービス・塾サイト・まとめサイトのドメインではない（例: 個人ブログ、「〇〇中学 過去問まとめ」のようなアグリゲータ、会員制の過去問データベースサービス）

## Step 3. 保護者確認（必須チェックポイント）

以下を提示し、承認を得るまでダウンロードに進まない:

```
候補ドメイン: https://www.example-school.ac.jp
過去問公開ページ: https://www.example-school.ac.jp/admission/pastexam/
公開されている年度・科目: 2025年度・2024年度（国語・算数・理科・社会）
この情報で合っていますか？ダウンロードを進めてよいですか？
```

承認が得られない場合、または候補ドメインに確信が持てない場合は、ここで停止して人間の判断を仰ぐ。

## Step 4. ダウンロード

- 承認された公式ドメイン配下のURLのみ WebFetch/ダウンロードする
- ログインを要求された、CAPTCHA が出た、有料ページに誘導された場合は即座に停止し、その旨を報告する
- 保存先: `data/target-school/kakomon-raw/<年度>/`（**gitignore 対象**。既存の `data/textbooks/` と同じ扱い。`.gitignore` に未登録なら追加する）
- 各ファイルと同じディレクトリに `manifest.json` を作り、以下を記録する:

```json
{
  "school_name": "架空学園中等部",
  "official_domain": "https://www.example-school.ac.jp",
  "fetched_at": "2026-07-07",
  "files": [
    {"year": 2025, "subject": "math", "source_url": "https://www.example-school.ac.jp/.../2025-math.pdf", "local_path": "2025/math.pdf"}
  ]
}
```

## Step 5. 完了報告

- 取得できたファイル一覧（年度・科目・出典URL）
- 取得できなかった年度・科目があれば理由
- 次のステップ: `SETUP.md` Part 3-1 に従い、この過去問を分析して
  `data/target-school/{long-term-plan,difficulty-anchor,math-analysis,kokugo-analysis}.md` を書き直す
- **念押し**: 取得した過去問PDFを外部AIに読ませて分析する場合も、これは公式無料公開であって
  再配布・商用利用の許諾ではないこと、送信先AIサービスの学習利用拒否・データ保持設定を確認してから送ることを保護者に再確認する

## やらないこと

- 個人ブログ・まとめサイト・SNS投稿からの過去問取得
- 塾の会員限定ポータル・過去問販売サービスへのログイン
- 「公式サイトで見つからなかったから」という理由での第三者サイトへのフォールバック
- 見つけたPDFの全文をそのまま `data/target-school/*.md` に転記すること（`_shared/question-rules.md` の丸写し禁止ルールに従い、構造・配点・頻出単元の分析に留める）
