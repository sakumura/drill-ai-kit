# Dogfood 観察ポイント

**自動スペック（`tests/e2e/dogfood-lesson-complete.spec.ts`）で機械検証される項目**と、**エージェントが目視で観察する項目**を分離している。自動分が ✅ でも保護者目視は必ず実施する。

## 自動検証（Playwright spec が拾う）

| # | 項目 | 検証内容 |
|---|------|---------|
| 1 | hints[0] 正解判定 | 全問 hints[0] クリック → `.question-flash__choice--correct` CSS |
| 2 | 不正解フィードバック | hints[1] クリック → `.question-flash__choice--wrong` or answer-label 表示 |
| 3 | コンソールエラー | favicon/ResizeObserver 除外後 0 件 |
| 4 | 長文正解肢表示 | answer ≥ 20字 の選択肢ボタンがビューポート内 |
| 5 | 漢字文字化け | ボタンテキストに answer が完全一致で含まれる |
| 6 | SVG 描画 | figure_svg 問題に path/rect/circle 等の描画要素あり |

**自動判定が ❌ なら即修正対象**。spec 実行結果は `data/analysis/dogfood-YYYY-MM-DD.md` に自動出力。

## 保護者目視（手動チェック・判定は ✅ / ⚠️ / ❌ の3段階）

### 問題品質（自動では拾えない質的観察）

- [ ] 問題文は小5にわかりやすいか（漢字・語彙・論理構造）
- [ ] 計算問題: 正解選択肢の計算が合っているか（自動ではヒント列の整形しか見ない）
- [ ] ダミー選択肢（hints[1]/hints[2]）は誘惑性があるか（明らかな外れ値は NG）
- [ ] 解法ステップ（solution_steps）の粒度・わかりやすさ
- [ ] 分数表示 FractionText の視覚的崩れ（自動の CSS チェックでは拾えない）
- [ ] 国語の因果関係: 「○○したから→□□になった」形式
- [ ] common_mistakes が実在のつまずきパターンを反映しているか

### UX

- [ ] タイマー秒数は適切か（算60s / 国30s 想定 — 2026-04-20 以降）
- [ ] 不正解表示6秒は長すぎ/短すぎないか
- [ ] 解法例の表示はわかりやすいか
- [ ] ボタンのタップしやすさ
- [ ] テキストの読みやすさ
- [ ] 思考時間の動的調整（accuracy ベース短縮）の挙動
- [ ] 途中再開時の「○問目からつづき」表示

### 動作系バグ（自動で拾えない挙動）

- [ ] アニメーションが正常か
- [ ] 画面遷移のタイミング
- [ ] 解答ログが localStorage/R2 write queue に正しく入るか
- [ ] ケアレスミス表示の正確性
- [ ] スキルマスターの正答率集計（unit_id ベース）

## 判定の使い分け

| 判定 | 意味 | 対応 |
|------|------|------|
| ✅ | 問題なし | 次へ |
| ⚠️ | 改善余地あり | レポートに記録、次回調整 |
| ❌ | 即修正が必要 | dogfood 完了後に対応（generate-drill-lesson 再生成 or handwritten JSON 修正） |
