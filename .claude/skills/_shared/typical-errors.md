# typical_errors 辞書（distractor の出典）

`hints[1]` `hints[2]` の典型誤答は以下のカテゴリから選ぶ。各カテゴリは「教科書の解答集に書かれている本物の誤答パターン」であり、機械的な数値変換（÷2・×2・桁ずらし）とは区別する。

## カテゴリ一覧

| カテゴリ | 例（算数） | 例（国語） |
|---|---|---|
| 単位忘れ | cm² を cm にする / m² を cm² で答える | — |
| 公式の取違え | 三角形 ÷2 忘れ / 平行四辺形に ÷2 する / (上底+下底) を (上底×下底) | — |
| 通分・約分ミス | 分母どうし足す（4/10 型）/ 約分忘れ / 通分の最小公倍数を取り違え | — |
| 逆算の方向ミス | ×→÷ を逆 / 移項符号ミス | — |
| 内角和の取違え | 180° と 360° の取違え / 残り角の引き忘れ | — |
| 同位角・錯角混同 | 同位角の代わりに補角(180-x) | — |
| 字形の混同 | — | 「校」と「高」/「員」と「院」/「動」と「働」 |
| 同音異字 | — | 「公」と「工」/「報」と「方」 |
| 受身/可能/自発の混同 | — | 「読まれる」「読める」「読ませる」 |
| 本文反対選択 | — | 本文と逆のことを断定する選択肢 |
| 因果の逆転 | — | 結果と原因を逆に書く |

## 禁止 distractor

以下のパターンは機械的・教育的妥当性に欠けるため distractor として使用禁止:

- **機械テンプレ**: ÷2 / ×2 / ÷10 / ×10 / 桁ずらし / 符号反転
- **明らかなダミー**: 「△場合による」「わからない」「その他」「上記すべて」
- **構文不一致**: `hints[0]` と極端に長さが違う選択肢（短すぎ・長すぎ）

## 運用ルール

1. 問題執筆時、該当カテゴリがなければ新規追加するより構成表の問題自体を差し替える
2. 同一カテゴリを同一レッスン内で 3 問以上連続で使うのは禁止（パターン偏り）
3. distractor は R0-R16 機械チェック（validate_lesson_format.py）の R10 で検証される
