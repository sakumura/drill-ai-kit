# 弱点スコア降格・昇格ロジック

Phase 3 の自動提案と Phase 4a の弱点プロファイル更新で使う。エージェントが機械的に適用する。

**2026-04-24 §4d 志望校アンカー改訂**: 難易度は §4d の d1-d5 志望校アンカー基準に統一。降格/昇格判定も d5（過去問大問 3(3)(4) 相当）を含めて評価。参照: `_shared/question-rules.md §4d` + `data/target-school/difficulty-anchor.md`

## スコア降格テーブル（プレイ結果ベース・§4d 新定義）

1h で取得した「パターン別 正答率 × 難易度 × サンプル数」から機械的に降格幅を決める。**d5 を含む成功は重み大きく、d2 のみの成功は軽く判定**する。

| 条件 | 降格幅 |
|------|-------|
| サンプル 1-2問のみ | **据置**（判定保留） |
| サンプル 3問以上 × 100% × d2 のみ | **-3**（ウォームアップ枠のみ達成は軽扱い） |
| サンプル 3問以上 × 100% × d3 含 | **-8** |
| サンプル 3問以上 × 100% × d4 含 | **-12** |
| サンプル 3問以上 × 100% × **d5 含** | **-18**（最難問題クリア） |
| サンプル 3問以上 × 100% × **d5 多数（2問+）** | **-25**（克服確定） |
| サンプル 3問以上 × 80-99% | **-5** |
| サンプル 3問以上 × 60-79% | **+5** |
| サンプル 3問以上 × <60% | **+15** |

### 補足

- 「d3 含」「d4 含」「d5 含」は、そのパターンの問題のうち少なくとも1問が `test_difficulty_reference.md` の該当 d 相当以上と判定できる場合
- **d5 を解けたときだけ「本当に克服した」と判定**（§4d: d5 = 過去問大問 3(3)(4) 相当の発展問題）。d3-d4 までの100%は「再認テスト化」疑いが残る
- 降格下限は **10**（それ以下にはしない）
- テスト範囲外パターンでも同ルールを適用（克服してもテスト外だから据置にはしない）
- 「今回初めて再出題されて正解になった」リベンジ成功は **追加 -5**（克服マーク）
- **3択UI のガイドレール効果の疑いがある場合は降格を 1/2 に緩和**（立式選択主体で d3 100% のような場合）

## スコア昇格計算式（検出ベース・従来通り）

新規検出・再検出時のスコア計算:

| 要素 | 重み |
|------|------|
| severity | critical=30, high=20, medium=10, low=5 |
| detection_count | ×3 |
| 最終検出からの日数 | ×(-5/日) |
| テスト失点との関連 | +20 |
| understanding_level=1 | +15 |

## 難易度昇格ロジック（training-plan.md 改訂用）

直近 n 日の正答率から各テーマの下限 difficulty をどれだけ上げるか決める。Phase 3 で自動計算し、training-plan.md の残り Day 全てに反映する。

| 直近 n 日の正答率 | サンプル | 下限改訂 |
|------------------|---------|---------|
| 100% 連続 | 2日 | **+1** |
| 100% 連続 | 3日以上 | **+2** |
| 95%以上 | 3日平均 | +1 |
| 85-95% | 3日平均 | 据置 |
| 70-85% | 3日平均 | 据置（ただし下限帯を1問混ぜる） |
| <70% | 3日平均 | -1（ただし training-plan の下限は割らない） |

**改訂の反映方法**: training-plan.md の元の Day別表は上書きせず、「## 現在地」セクションに以下の履歴を追記する:

```markdown
### YYYY-MM-DD 改訂（〇〇日プレイ結果を反映）
- Day N を d2:X/d3:Y/d4:Z に変更（元: d2:a/d3:b/d4:c）
- 根拠: 連続100%/d3-4余裕あり → 下限+1
```

## Phase 3 での使い方

Phase 3 で以下のテーブルを埋める:

```markdown
### A. 弱点スコア調整（上記降格テーブルに従う）
| パターン | 現score | 根拠（今回プレイ内訳） | 新score |
|---------|---------|----------------------|--------|
| math:gyakuzan | 63 | d4四則混合逆算 3問含め9/9 | 48 (-15) |

### B. 難易度昇格/降格
| Day | 日付 | 原案ミックス | 改訂ミックス | 理由 |
|-----|------|-------------|-------------|------|
| Day9 | 4/14 | d2:15/d3:11/d4:4 | d2:10/d3:13/d4:7 | 2日連続100%→+1 |
```

エージェントが機械計算して提案し、保護者には**「この方針で Phase 4 を回していい？」** だけ聞く。個別の降格幅や昇格幅は聞かない（聞くのは修正要求があった場合のみ）。
